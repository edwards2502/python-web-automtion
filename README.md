# python-web-automation
# Automação de Preenchimento de Formulários com Python

## Visão Geral do Projeto
Este projeto utiliza Python e PyAutoGUI para automatizar o preenchimento de formulários a partir de dados armazenados em arquivos CSV. O objetivo é reduzir o trabalho manual repetitivo e tornar o processo de entrada de dados mais eficiente.

## Principais Funcionalidades
- Leitura de dados em arquivos CSV.
- Automação do preenchimento de formulários.
- Redução de tarefas repetitivas de entrada de dados.

## Tecnologias Utilizadas
- Python
- PyAutoGUI
- Arquivos CSV
